# Support

Constructa is an early-stage open-source project maintained on a best-effort basis.

## Questions and usage help

Before asking for help:

1. Read the [README](README.md) and relevant package documentation.
2. Search existing issues for the same question or problem.
3. Confirm the problem still occurs on the latest default branch.

If you still need help, open a GitHub issue with enough context to reproduce or understand the problem. Use the bug report template for defects and the feature request template for proposed improvements.

## Security and conduct reports

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report conduct incidents privately according to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not include credentials, private data, or other sensitive information in public issues.
